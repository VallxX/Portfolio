Script Bash — Gestion de versions

Script Bash reproduisant un système de versioning simplifié, inspiré de Git, entièrement développé en shell.

Fonctionnalités

  • add, commit, amend
  • diff, checkout
  • log, reset
  • Gestion des erreurs

Architecture

  • Dossier .version/
  • Fichiers versionnés numérotés
  • Logs horodatés
  • Patches avec diff / patch

Simulation terminal

terminal — ./version.sh

Compétences mises en œuvre

  • Bash
  • Scripting système
  • Automatisation
  • Gestion des erreurs
